# Archived identity references

These 46 images previously shared the active `data/references/<persona>/`
directories with the five confirmed canon boards. They contain old anchors,
bootstrap generations, body/pose studies and support views. Their original
bytes are preserved; names such as `verified` do not make them canon.

The move and SHA-256 inventory is recorded in
[`../references/manifest.json`](../references/manifest.json). Active reference
folders now contain only the existing `canon-01.png` boards. Do not automatically
copy archive images back into the active pack.

On-device bank rebuilds keep previous banks in the ignored `persona-banks/`
subdirectory before installing a complete freshly built set. Test outputs stay
under ignored `data/runs/local-dream-realism/`.
